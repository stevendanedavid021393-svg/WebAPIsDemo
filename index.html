APIs Used

API #1: Geolocation API

The Geolocation API lets a web page ask the browser for the user's current physical location. Calling navigator.geolocation.getCurrentPosition() prompts the user for permission, then returns latitude, longitude, and accuracy. In this demo, clicking Get My Location triggers this call, and the result is displayed above. If the user denies permission, the device can't get a fix, or the request takes too long, the API reports an error instead — which this demo catches and turns into a friendly message.

API #2: Web Storage API

The Web Storage API lets a page save simple key/value data directly in the browser using localStorage, with no server or database involved. Data saved this way persists across page reloads and browser restarts until it's explicitly cleared. In this demo, every location successfully retrieved is saved to localStorage so it can be shown again the next time the page loads, and the Clear Saved Location button removes it.
